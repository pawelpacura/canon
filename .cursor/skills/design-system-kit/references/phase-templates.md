# Szablony faz (wklejaj do chatu)

## Phase N Checklist

```markdown
### Phase {N} Checklist
- [ ] P{N}.a …
- [ ] P{N}.b …
Exit: …
```

## Phase N Summary

```markdown
### Phase {N} Summary
- Done: …
- Figma: node `{id}` — {url}
- Repo files: …
- Validations: …
- Risks / follow-ups: …
STOP — czekam na approve fazy {N} zanim ruszę fazę {N+1}.
```

## Gap analysis (Phase 0)

```markdown
### Gap analysis
- Figma only: …
- Repo only: …
- Conflicts: …
- Proposed scope: …
- Out of scope: …
```

## Po approve — ack

```markdown
Approve fazy {N} przyjęty → startuję fazę {N+1}: {nazwa}.
```

## Visual QA (Phase 1 / 3) — pełny opis w `visual-qa.md`

```markdown
### Visual QA
- Rodzeństwo: {modal|panel|button|…} — zgodne / różnice: …
- Anti-slop: OK | problem: …
- Copy (GUIDELINES/Storybook): OK | …
- A11y: focus / labels / reduced-motion — …
```

## Słowa uznawane za approve (nieexhaustive)

`ok`, `OK`, `approve`, `approved`, `akceptuję`, `akceptuje`, `jedź`, `dalej`, `rób kod`, `leć z kodem`, `faza 2`, `go`, `LGTM`.

Jeśli niejasne — jedno krótkie pytanie, nie zakładaj milczącego approve.
